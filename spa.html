Imagine this were a radio station's home page. On-air, Programs, Listen live, and the drawer leave this site for the listener app at test.q.spinitron.com. That app keeps playing while you browse. A stylesheet supplies the look and feel to the listener app so its top bar, player and text pick up this site's colors and type.

The nav links here have query param laf_css= and return_url= pointed at https://raw.githubusercontent.com/spinitron/TEST/refs/heads/master/testradio.css. Spinitron can store your custom css file on the server for you so you don't need laf_css= on your links.

Spinitron provides a number of named stock stylesheets which you can select with query param laf= and testradio is one of them. See docs on the forum for the others.Preview the named stock: ?laf=testradio.

The station name in the topnav of the listener app returns here because return_url= points back to this page.

The app is not pixel-identical to this page. Different HTML, different class names. The goal is to be close enough.

Source: this page, the CSS this site hosts, this repo. Questions in the forum or contact Spinitron.
